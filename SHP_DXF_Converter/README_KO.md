# SHP → DXF Converter (Windows 11)

## 확정된 제작 조건
- 속성정보: 선택한 SHP 속성 필드를 CAD TEXT로 표시
- 좌표계: 사용자가 대상 EPSG 코드를 선택/입력
- 변환 범위: SHP 전체 레코드 일괄 변환
- DXF 버전: AutoCAD 2007 호환 (DXF R2007)

## 기능
- SHP 불러오기 및 DBF 필드 목록 표시
- 선택한 속성 필드를 각 객체 대표 위치에 문자로 표기
- 속성 문자 글꼴 선택 (맑은 고딕, 굴림, 돋움, Arial, Romans/Simplex SHX)
- 속성 문자 높이 직접 입력
- 도형 색상과 속성 문자 색상을 AutoCAD ACI 색상표에서 선택
- 원본 `.prj`에서 좌표계를 읽고 입력한 EPSG로 변환
- 폴리곤/멀티폴리곤 외곽선과 내곽선, 폴리라인, 포인트 변환
- 도형은 `SHP_GEOMETRY`, 속성 문자는 `SHP_ATTRIBUTES` 레이어로 생성
- 변환 진행률 및 완료 요약 표시

## 실행 방법
1. Windows 11에 Python 3.10 이상을 설치합니다. 설치 시 PATH 추가를 선택합니다.
2. 압축을 푼 폴더에서 `build_exe.bat`을 더블클릭합니다.
3. 빌드가 끝나면 `dist\SHP_DXF_Converter.exe`가 생성됩니다.
4. EXE를 실행해 SHP를 선택하고 대상 EPSG를 입력한 뒤 DXF 변환을 누릅니다.

## 좌표계 주의
- SHP와 동일한 이름의 `.prj` 파일이 필요합니다.
- 대상 좌표계는 EPSG 코드로 입력합니다. 예: `EPSG:5179`, `EPSG:5186`, `EPSG:4326`
- EPSG:5174 등 특정 좌표계를 사용할 때는 해당 데이터의 실제 원본 좌표계와 단위/축 순서를 확인하세요.
- 이 프로그램은 원본 SHP의 좌표계를 자동 추측하지 않습니다.

## 글꼴 및 색상 설정
- 도형 색상은 `SHP_GEOMETRY` 레이어 색상으로 지정되며 객체는 BYLAYER 방식입니다.
- 속성 문자 색상은 `SHP_ATTRIBUTES` 레이어 색상으로 지정됩니다.
- 글꼴은 DXF 문자 스타일에 기록됩니다. AutoCAD PC에 해당 글꼴 파일이 설치되어 있어야 동일하게 표시됩니다.
- 문자 높이는 도면 좌표 단위 기준으로 입력합니다. 예를 들어 미터 좌표계에서 1.5는 1.5m가 아니라 CAD 도면 단위 1.5입니다.

## 속성 문자 주의
- 선택한 필드는 각 객체의 대표 위치에 `필드명: 값` 형식으로 표시합니다.
- 폴리곤의 대표 위치에 배치하므로 복잡한 지적도에서는 문자가 겹칠 수 있습니다.
- 문자 높이는 DXF 좌표 단위 기준 1.5로 설정되어 있습니다. CAD에서 전체 선택 후 문자 높이를 조정할 수 있습니다.
- 모든 필드를 선택하면 도면이 매우 복잡해질 수 있으므로 PNU/지번 등 필요한 필드만 선택하는 것을 권장합니다.

## 제한 및 검증
- 2D DXF로 저장하며 Z 좌표는 사용하지 않습니다.
- SHP의 도형은 CAD 폴리라인/포인트로 변환됩니다. 곡선은 원본 정점 기반의 직선 세그먼트로 저장됩니다.
- 변환 후 AutoCAD에서 좌표, 객체 수, 레이어, 지번 문자 위치를 표본 확인하세요.
- 대용량 연속지적도는 메모리 및 CAD 성능에 따라 처리 시간이 길어질 수 있습니다.


## 배치파일 실행 오류가 발생하는 경우
- `build_exe.bat`를 최신 버전으로 실행합니다.
- Python 3.10 이상 설치 시 `Add Python to PATH`를 선택합니다.
- 명령 프롬프트에서 `python --version`이 실행되는지 확인합니다.
- 빌드 과정에서 인터넷 연결이 필요합니다.


## Python 없이 사용할 EXE 만들기 (GitHub Actions 방식)
이 프로젝트에는 Windows 빌드 자동화 파일 `.github/workflows/build-windows.yml`이 포함되어 있습니다.
GitHub의 Windows 실행 환경에서 Python과 라이브러리를 묶어 단일 EXE를 생성하므로,
완성된 EXE를 실행하는 PC에는 Python을 설치할 필요가 없습니다.

1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다.
2. 이 ZIP의 압축을 풀고 파일 전체를 저장소에 업로드/커밋합니다. `.github/workflows/build-windows.yml`도 포함되어야 합니다.
3. 저장소의 **Actions** 탭으로 이동합니다.
4. 왼쪽 **Build Windows EXE** 작업을 선택하고 **Run workflow**를 누릅니다.
5. 작업이 성공하면 실행 결과 화면 아래 **Artifacts**에서 `SHP_DXF_Converter-Windows11`을 다운로드합니다.
6. ZIP 압축을 풀면 `SHP_DXF_Converter.exe`가 있습니다. 이 EXE는 Python 없이 실행할 수 있습니다.

참고:
- GitHub 계정과 저장소가 필요합니다. 공개/비공개 저장소 모두 가능하며, 계정의 Actions 사용 한도/정책이 적용됩니다.
- EXE는 Windows용으로 빌드됩니다. macOS/Linux에서 빌드한 파일이 아닙니다.
- Windows SmartScreen 또는 백신이 처음 실행을 경고할 수 있습니다. 출처를 확인한 뒤 실행 여부를 결정하세요.
- 이 대화의 실행 환경은 Windows 빌드 환경이 아니므로, 여기서 완성된 Windows EXE를 직접 실행 검증했다고 주장하지 않습니다.
